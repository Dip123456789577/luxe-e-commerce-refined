# LUXE E-commerce Refined

Act as a world-class UI/UX designer, senior frontend developer, and e-commerce product designer.

Build a complete, professional, premium e-commerce website with a stunning minimalistic design. Create a modern lifestyle and fashion shopping brand called LUXE.

Design: warm off-white backgrounds, black typography, beige accents, editorial serif headings, clean sans-serif body text, generous whitespace, premium photography, subtle animations, and responsive layouts.

Pages: homepage with hero, categories, trending products, new arrivals, bestsellers, promotional banners, testimonials, newsletter, and footer; shop/catalog with search, filters, sorting, and product grid; product details with gallery, variants, reviews, and add-to-cart; cart; checkout; order confirmation; wishlist; login/signup; account/order history; About, Contact, FAQ, and 404.

Functionality: working navigation, search, filtering, sorting, product variants, cart quantities, wishlist, persistent demo data, coupon validation, checkout form validation, notifications, and responsive mobile navigation. No dead buttons or fake payment confirmations.

Technology: React, TypeScript, Tailwind CSS, Lucide icons, reusable components, realistic mock product data, and clean maintainable code. Integrate Supabase only if connected and appropriate. Keep secrets out of frontend code.

Make every page visually polished, accessible, mobile-friendly, and production-oriented. Use high-quality relevant product images, consistent spacing, realistic content, and a premium editorial shopping experience. Build the shared design system and homepage first, then implement the remaining pages and connect the major interactions.                                                                                                                                                                                                                                                                                                                                                                                    Now act as a senior UI/UX auditor and frontend engineer. Review the entire website you just created and improve it to an exceptionally polished premium e-commerce standard.

Improve typography, whitespace, visual hierarchy, image quality, product card consistency, navigation, mobile responsiveness, micro-interactions, loading states, and checkout usability. Remove generic AI-generated design patterns and any unnecessary visual clutter.

Test every navigation link, product filter, search action, variant selector, add-to-cart button, quantity control, wishlist action, and form. Fix all broken interactions, console errors, layout issues, and mobile overflow. Keep the existing brand identity and working features intact. Do not remove existing functionality just to simplify the design.
